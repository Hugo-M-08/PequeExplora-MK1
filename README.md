# PequeExplora 🌟
> Una aventura de aprendizaje interactivo para los más pequeños.

**PequeExplora** es una aplicación móvil educativa diseñada para estimular la curiosidad infantil. El objetivo principal es ofrecer un entorno seguro y lúdico donde los niños puedan aprender conceptos básicos mediante la exploración visual y auditiva.


## 🎯 Objetivos del Proyecto
- Facilitar el aprendizaje autónomo en niños de 3 a 6 años.
- Implementar una interfaz de usuario (UI) intuitiva con alta respuesta visual y sonora.
- Aplicar principios sólidos de programación móvil y arquitectura de software.

## 🛠️ Stack Tecnológico
Para este proyecto se utilizaron las siguientes tecnologías:

* **Lenguaje:** Swift
* **Interfaz:** SwiftUI y Storyboard
* **Arquitectura:** MVVM (Model-View-ViewModel) para una separación de responsabilidades limpia.
* **Persistencia de Datos:** Firebase Realtime Database.
* **Multimedia:** Lottie para animaciones / MediaPlayer para sonidos.

## ✨ Características Principales
* **Módulos de Aprendizaje:** Exploración de colores, números, animales español - ingles.
* **Interactividad:** Sonidos y animaciones al tocar elementos en pantalla.
* **Interfaz Kids-Friendly:** Botones grandes, colores vibrantes y navegación simplificada.
